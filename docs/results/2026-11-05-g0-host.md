# G0: host reference, 2026-11-05

Host: Ryzen 7 5800X (8 cores, 16 threads), 31 GB, CachyOS, GCC and gfortran 16.2.1, Open MPI
5.0.11, CMake 4.4.5. Source: AmberTools26 (`scripts/fetch-sources.sh`, sha256 verified).

## Build
`cmake -DCOMPILER=GNU -DMPI=FALSE -DCUDA=FALSE -DOPENMP=FALSE -DINSTALL_TESTS=TRUE
-DDOWNLOAD_MINICONDA=FALSE -DBUILD_PYTHON=FALSE -DBUILD_PERL=FALSE -DCMAKE_POLICY_VERSION_MINIMUM=3.5`:
rc 0 in 15 s. `make -j14 sander teLeap`: 49.73 s wall, 443.98 s CPU, peak RSS 372,400 kB.
A second tree with `-DMPI=TRUE`, `make -j14 sander.MPI`: 76.86 s, peak 374,956 kB.

## PrP benchmark box
`scripts/g0-prp-bench.sh`, inputs in `systems/prp-1qm0/`. PDB 1QM0 holds residues 125-228 only
(877 heavy atoms; teLeap adds 817). ff14SB, TIP3P, `solvateoct` buffer 19 A, 3 Na+:
16,071 waters (the reference work used 16,089), **49,910 atoms**. Disulfide 179-214.
Minimization 1,000 cycles, 10 ps heating to 310 K, 20 ps Berendsen NpT: mean density 0.9813
g/cm3, 0.9872 at the end of the benchmark runs, temperature 310.0 K, 0 `vlimit` warnings.

## Timing: 1,000 steps NpT, PME, cut 8 A, 2 fs, no trajectory output
Three rounds, interleaved 1, 8, 14 ranks. Raw: `2026-11-05-g0-prp-bench.tsv`. Wall clock of the
whole process, including setup. The desktop was in normal use.

| Ranks | Mean ns/day | Min | Max | Spread |
|---|---|---|---|---|
| 1 (serial `sander`) | 0.961 | 0.959 | 0.963 | 0.4 % |
| 8 (`sander.MPI`, one per core) | 4.471 | 4.210 | 4.659 | 10.0 % |
| 14 (`sander.MPI`, hardware threads) | 3.444 | 3.083 | 3.657 | 16.7 % |

14 ranks are slower than 8: sander's replicated-data MPI does not gain from SMT here, and the
desktop's own load shares those threads. **The host's best is 4.659 ns/day.** That is the number
the card has to beat. The 1-minute load average column was 9.99 to 15.38 at the start of the
serial runs because it still carried the preceding 14-rank run.

An early estimate in the conversation of about 2.9 ns/day (from heating file times) was below
these measurements.
