# Intel-Phi-AmberMD

Molecular dynamics from the FOSS parts of the Amber suite (AmberTools) on Intel Xeon Phi
Knights Corner coprocessors, without Intel compilers, MPSS or MKL.

First target: one Xeon Phi 7120A. Later target: a rack of 3120A cards.

Status: planning. Nothing has run on a card yet. See `docs/plan.md` when it lands.
